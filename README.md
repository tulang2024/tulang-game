# 挂机传奇 · 在线版（土狼摸鱼大师 v1.0.3）

一款纯前端 + 原生 Node 服务端的放置类（挂机）小游戏：自动打怪、爆装备、强化升星、行会、交易行、全网排行榜。

> 本仓库**不含任何玩家隐私数据**。下载后第一次启动会自动生成空的账号/排行榜/行会数据文件。

---

## 一、文件说明

| 文件 | 作用 |
|------|------|
| `index.html` | 游戏前端主程序（也是联机版入口，放到服务端同目录即可） |
| `server.js` | 后端服务：托管游戏页面 + 排行榜 API + 云存档 API（零依赖，纯 Node） |
| `package.json` | 启动脚本，`npm start` 即可运行 |
| `土狼摸鱼大师-v1.0.3.html` | **单机版**：双击直接用浏览器打开就能玩，无需服务器、无排行榜 |
| `GAME_DESIGN.md` | 游戏设计文档（怪物曲线、地图、装备、行会等完整设定） |
| `使用说明-永久方案.md` | 玩家使用与排障说明 |

> 运行后会自动产生 `accounts.json` / `rank.json` / `market.json` / `guilds.json` 四个数据文件，**不要**上传到公开仓库（含你的账号和进度，属于隐私）。

## 二、自己本地怎么跑（5 分钟）

**方式 A：联机版（带排行榜、云存档，需要 Node.js）**

1. 安装 Node.js（官网 https://nodejs.org ，下载 LTS 版，一路下一步安装完）。
2. 把本仓库文件夹放到任意位置，比如 `D:\games\guaji-legend`。
3. 进入该文件夹，在地址栏输入 `cmd` 回车，弹出命令行。
4. 执行：
   ```bash
   npm start
   ```
   看到 `guaji-legend server listening on 0.0.0.0:3000` 就成功了。
5. 浏览器打开 `http://localhost:3000/` 即可开玩。

**方式 B：单机版（最简单，完全不用装任何东西）**

直接**双击 `土狼摸鱼大师-v1.0.3.html`** 用浏览器打开就能玩。进度保存在你本机浏览器里（换电脑不互通）。

## 三、发布到 Gitee（小白一步步教程）

> Gitee 是国内的代码托管网站（类似 GitHub，国内访问快）。把代码传上去，既能备份，也能分享给别人。

### 第 1 步：注册 Gitee
1. 打开 https://gitee.com ，点右上角「注册」，用手机号或邮箱注册一个账号。

### 第 2 步：新建仓库
1. 登录后点右上角「+」→「新建仓库」。
2. 仓库名称填 `guaji-legend`（英文，不能中文和空格）。
3. 仓库介绍随便写，比如「挂机传奇在线版小游戏」。
4. 勾选「私有」或「公开」都行（想让别人看到就选公开）。
5. **「初始化仓库」的勾全部取消**（不要勾 README/.gitignore 模板，我们用自己的）。
6. 点「创建」。

### 第 3 步：把游戏文件传上去（最简单：网页拖拽，无需装 Git）

1. 进入刚建好的仓库页面，点「文件」→「上传文件」。
2. 把本文件夹里的这些文件**直接拖进去**（按住 Ctrl 多选）：
   - `index.html`
   - `server.js`
   - `package.json`
   - `README.md`（就是本文件）
   - `GAME_DESIGN.md`
   - `使用说明-永久方案.md`
   - `土狼摸鱼大师-v1.0.3.html`
   - `.gitignore`
3. ⚠️ **千万不要上传** `accounts.json`、`rank.json`、`market.json`、`guilds.json`（这些你本地运行后才会出现，含隐私）。如果电脑里还没有这几个文件，那就什么都不用管。
4. 页面底部填写提交说明，比如「首次发布 v1.0.3」，点「提交」。

✅ 完成！其他人就能在 Gitee 上看到你的游戏源码了。

### 第 4 步（进阶，可选）：用 Git 命令行发布

如果你以后经常更新，可以装 Git（https://git-scm.com）后用命令行：

```bash
# 进入项目文件夹后执行
git init
git remote add origin https://gitee.com/你的用户名/guaji-legend.git
git add .
git commit -m "首次发布 v1.0.3"
git push -u origin master
```

> 因为仓库里带了 `.gitignore`，上面 `git add .` 会自动跳过隐私数据文件，很安全。

## 四、别人怎么玩你发布的游戏？

- **单机版**：把你仓库里的 `土狼摸鱼大师-v1.0.3.html` 下载下来，双击浏览器打开即玩。
- **联机版（带全网排行榜）**：需要在**有公网 IP 的服务器**上运行 `npm start`（比如腾讯云/阿里云轻量服务器，或免费的 Render、Railway 平台），再把服务器的地址发给朋友。
  - ⚠️ 注意：**Gitee 只存代码，不能直接运行游戏**。想在手机/其他电脑上联机，必须自己部署到一台云服务器。

## 五、常见问题

**Q：上传时把 accounts.json 传上去了，怎么办？**
A：立刻去仓库里把这几个数据文件删掉（仓库「文件」→ 找到文件 → 删除），并修改过密码。下次记得只传源码，不传数据。

**Q：npm start 报错？**
A：确认已安装 Node.js；在文件夹里按住 Shift 右键「在此处打开 PowerShell」，再输入 `node server.js` 看具体报错。

**Q：排行榜为什么是空的？**
A：新仓库/新部署本来就是空榜，你玩一局、角色死亡或手动上报后就会出现记录。
